## 📌 About the Project

**CampusConnect** is a Smart Campus Management System designed to
simplify and improve everyday academic management.

The project provides a centralized platform for managing student
information, attendance records, assessments, authentication, and
academic analytics.

It aims to make campus operations more organized, efficient, and
accessible through a user-friendly web interface.

## ✨ Key Features

-   👨‍🎓 **Student Management** -- Manage student information and records.
-   📅 **Attendance Management** -- Maintain and track student
    attendance.
-   📊 **Academic Analytics** -- Access academic and attendance-related
    analytics.
-   📝 **Assessment Management** -- Manage student assessments.
-   🔐 **Authentication** -- Authentication API for secure access.
-   🌐 **Web Interface** -- Frontend built with HTML, CSS, and
    JavaScript.
-   ⚡ **REST API** -- Backend API powered by FastAPI.

## ⚙️ Installation & Setup

### 1. Clone the Repository

``` bash
git clone https://github.com/TECHANIKET7209/CampusConnect.git
```

### 2. Navigate to Project Directory

``` bash
cd CampusConnect
```

### 3. Create Virtual Environment

``` bash
python -m venv .venv
```

### 4. Activate Virtual Environment

**Windows:**

``` bash
.venv\Scripts\activate
```

### 5. Install Project Dependencies

Install the dependencies required by the project, including FastAPI,
Uvicorn, and the configured database libraries.

### 6. Run the Backend

``` bash
cd backend
uvicorn app.main:app --reload
```

### 7. Open API Documentation

After starting the backend, visit:

-   API Documentation: http://127.0.0.1:8000/docs
-   Alternative API Documentation: http://127.0.0.1:8000/redoc
-   Health Check: http://127.0.0.1:8000/health
